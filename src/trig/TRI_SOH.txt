'================================
' PROGRAM: TRI_SOH
' PURPOSE: Sine ratio opposite/hypotenuse
'================================

"TRI SOH"→TITLE
Prog "CFORMAT"

Input "Opp?",OPP
Input "Hyp?",HYP

HYP→POSVAL
5→VALMODE
Prog "CVALID"
If VALID=0 Then
 Return
IfEnd

If OPP<=0 Or OPP>HYP Then
 0→VALID
 "INVALID TRIANGLE"→ERRMSG
 Prog "CERROR"
 Return
IfEnd

OPP/HYP→RESVAL
"SIN="→RESLBL
1→RESMODE
Prog "CRESULT"

Pause
Return
