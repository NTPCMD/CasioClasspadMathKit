# Program Naming Rules

Use short ClassPad-compatible names with the following prefixes:

| Type | Prefix |
|---|---|
| Menu | `MN_` |
| Core | `CORE_` |
| Algebra | `ALG_` |
| Linear | `LIN_` |
| Geometry | `GEO_` |
| Measurement | `MES_` |
| Trig | `TRI_` |
| Stats | `STA_` |
| Finance | `FIN_` |
| Graph | `GRH_` |
| Utility | `UTL_` |

## Examples

- `ALG_QUAD`
- `ALG_SIMUL`
- `LIN_GRAD`
- `GEO_PYTH`
- `MES_CAR`
- `MES_COMPA`
- `TRI_SOH`
- `STA_MEAN`
- `FIN_COMP`
- `GRH_LINE`
- `CINPUT`
