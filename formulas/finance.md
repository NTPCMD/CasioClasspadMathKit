# Compound Interest

NAME:
Compound Amount

FORMULA:
A = P(1 + R/N)^(NT)

VARIABLES:
- P: Principal
- R: Annual rate as decimal (e.g., 0.05 for 5%)
- N: Compounds per year
- T: Time in years
- A: Amount

INPUTS:
- P, R, N, T

OUTPUTS:
- A

VALIDATION:
- P > 0
- n > 0
- t > 0

EXAMPLE:
- P = 1000, R = 0.05, N = 12, T = 2
- A ≈ 1104.94

PROGRAM NAME:
FIN_COMP
