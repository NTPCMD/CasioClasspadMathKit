# Compound Interest

NAME:
Compound Amount

FORMULA:
A = P(1 + r/n)^(nt)

VARIABLES:
- P: Principal
- r: Annual rate
- n: Compounds per year
- t: Time in years
- A: Amount

INPUTS:
- P, r, n, t

OUTPUTS:
- A

VALIDATION:
- P > 0
- n > 0
- t > 0

EXAMPLE:
- P = 1000, r = 0.05, n = 12, t = 2
- A ≈ 1104.94

PROGRAM NAME:
FIN_COMP
