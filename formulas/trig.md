# SOH Rule

NAME:
Sine from Opposite and Hypotenuse

FORMULA:
sin(θ) = opposite / hypotenuse

VARIABLES:
- θ: Angle
- opposite: Opposite side
- hypotenuse: Hypotenuse side

INPUTS:
- opposite
- hypotenuse

OUTPUTS:
- sin(θ)

VALIDATION:
- hypotenuse > 0
- 0 ≤ opposite ≤ hypotenuse

EXAMPLE:
- opposite = 3, hypotenuse = 5
- sin(θ) = 0.6

PROGRAM NAME:
TRI_SOH
